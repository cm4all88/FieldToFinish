# Crew Upload branding

Put the Parametrix logo here as `parametrix-logo.png` (a white or reversed version reads best on the
dark header band; about 300 x 90 px or larger). It is copied beside `CrewUpload.exe` on build.

Without it the header shows the company name as a wordmark. The colours are in `branding` in
`../job-folders.json` (`primaryColor`, `accentColor`); the shipped values are placeholders -- set them
from the Parametrix brand guide.
