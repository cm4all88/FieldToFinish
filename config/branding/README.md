# Crew Upload branding

From the Parametrix Brand Guide (November 2023), copied beside `CrewUpload.exe` on build:

| File | What |
|---|---|
| `parametrix-logo.png` | Primary logo (charcoal/red) for the white header. Guide p. 11. |
| `parametrix-logo-knockout.png` | Reversed/knockout logo, for dark backgrounds. Not used by the window today. |
| `parametrix-ix.png` | The ix formation, set bleeding off the bottom-left corner. Guide p. 15, 24. |

These were rendered from the brand guide PDF at 600 dpi. If marketing supplies the official PNGs
(Templafy, or marketingtoolbox@parametrix.com), drop them in under the same names.

The `branding` section of `../job-folders.json` holds the rest:

- Colours: Charcoal `#333333` and Parametrix Red `#EE3D24` (guide p. 18). Red is kept to the one primary
  button, problems and the spacer arrow -- the guide asks for red "sparingly".
- Fonts: the guide's Microsoft Office stand-ins -- Rockwell for Klinic Slab headlines, Franklin Gothic
  for body text. Klinic Slab / Franklin Gothic URW are used instead if installed.
- Each upload type's `color` (in `categories`) is from the secondary and tertiary palette, which the guide
  reserves for telling categories apart.

The name is always "Parametrix" in full, never "PMX" (guide p. 5).
