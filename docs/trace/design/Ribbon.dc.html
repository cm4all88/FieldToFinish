Proposed: the TRACE tab (dark Civil 3D theme shown; the light theme uses the same buttons)
12 buttons. Groups open a menu (Lines is open below) so every existing command is still two clicks away.
How it maps. The TRACE button opens the Start window and has Run TRACE in its menu. Points: point labels, spot elevations. Lines: label line, label between, stairs, bulk line labels, line inventory. Trees: trees, driplines. Draft: draw line, clean drafted. Tables: schedule, control table, legend. Reports and Help are new thin commands (open the CSV reports; open the documentation). Existing FTF* commands are unchanged. Civil 3D draws the ribbon, so branding is the tab name, panel names, icons and the TRACE button.
