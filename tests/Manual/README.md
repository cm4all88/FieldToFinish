Synthetic test kit for the manual Civil 3D checks (no real survey data).

- `trace-sample-points.csv` : 12 points, PNEZD, comma delimited (point, northing, easting, elevation, description).
- `rules.json` : neutral TRACE rules plus one fence line feature (layer `C-FENC`) for the line-labelling test.

Steps are in `docs/trace/MANUAL-VERIFICATION.md`.
